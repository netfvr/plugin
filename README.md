# plugin

Repositório de plugins QGIS.

## QField Cadastro Export (v1.0.0)

Plugin QGIS 3.34+ que exporta camadas selecionadas para um projeto autónomo
compatível com o QField (Android), preservando grupos/simbologia e removendo
etiquetas e anotações.

- ZIP instalável: `qfield_cadastro_export.zip`
- Código: pasta `qfield_cadastro_export/`
- Instalação: QGIS → Complementos → Gerir e Instalar Complementos → Instalar a partir de ZIP
